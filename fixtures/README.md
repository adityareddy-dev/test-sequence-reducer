These are synthetic Playwright tests of external JSON state. They do not launch a browser or test a real application. Each case has one flat spec, no hooks, no retries, one worker and explicit declaration order. `reset.mjs` restores a named clean seed before every candidate, writes the state path from `SEQUENCE_REDUCER_STATE` and emits its reset receipt as JSON.

`SEQUENCE_REDUCER_ATTEMPT` is the one-based probe number. The alternating control uses its parity to make repeat instability deterministic. Its variation models an unstable input, it is not random sampling.

The single case has one polluter and irrelevant tests. The pair requires a prepare test followed by the polluter. The setter-dependent case also needs setup, but its polluter fails if setup is removed. The cleaner restores state after pollution, and the independent target ignores that state. The cleaner-order case has a second polluter after cleanup, only that polluter supplies the intended failure. The target prerequisite fails alone and passes after setup. The failing predecessor must invalidate a candidate even if the target also fails. The fingerprint case needs setup to keep the intended failure, removing setup produces a different target error.

Expected outcomes live in `cases.mjs`. The acceptance runner checks exact witnesses, repeat confirmation and deletion checks for positive cases, plus rejection of the five controls. The fingerprint and setter-dependent witnesses remain inconclusive for deletion-minimality because a removal produces a different failure or a predecessor fails. Those finite expectations establish fixture behavior only, they do not estimate accuracy on other suites.
